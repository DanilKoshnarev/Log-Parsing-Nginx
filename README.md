# Скрипт для обработки лог-файлов Nginx  

## Описание работы программы  

### Основные функции  

#### **Функция `rotate_files`**  
- Проверяет наличие ротационных файлов (`lines.txt.1`, `lines.txt.2` и т.д.).  
- Переименовывает текущий файл `lines.txt` в следующий по очереди.  

#### **Функция `parse_logs`**  
- Проходит по всем лог-файлам в директории `/var/log/nginx`, включая ротационные файлы (`access.log`, `access.log.1`, `access.log.2` и т.д.).  
- Ищет строки, соответствующие заданной маске (`pattern`).  
- Записывает найденные строки в файл `lines.txt`.  
- При достижении размера файла 200 КБ выполняется ротация.  

---

## Детальное описание функций  

### **Функция `get_log_files`**  
- Возвращает список лог-файлов из указанной директории.  

### **Функция `read_lines_from_file`**  
- Читает строки из лог-файла и возвращает их в виде генератора.  

### **Функция `filter_lines`**  
- Принимает регулярное выражение и генератор строк.  
- Возвращает только те строки, которые соответствуют шаблону.  

### **Функция `write_lines_to_file`**  
- Записывает строки в файл.  
- Производит ротацию при достижении заданного размера файла (по умолчанию 200 КБ).  

### **Функция `parse_logs`**  
- Основная функция, которая связывает все остальные:  
  1. Получает список лог-файлов через `data_source`.  
  2. Читает строки из каждого файла.  
  3. Применяет фильтр к строкам (`filter_func`).  
  4. Записывает отфильтрованные строки в файл через `storage_func`.  

---

## Гибкость подхода  
- `data_source` может быть заменен на любую другую функцию, которая возвращает строки (например, данные из сети или базы данных).  
- `filter_func` можно заменить на другую функцию, если требуется другая логика фильтрации.  
- `storage_func` можно заменить на функцию, которая сохраняет данные, например, в базу данных или отправляет по сети.  

Такой подход делает программу гибкой, расширяемой и удобной в поддержке.
